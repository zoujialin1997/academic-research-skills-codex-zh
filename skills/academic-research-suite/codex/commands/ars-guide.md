以交互式引导响应新手求助（「新手教程」「怎么用」「guide」等），**不进入具体工作流**。全程遵守「固定选项点选协议」与「专业术语通俗解释」，用简体中文、平实的语言引导。

## 流程

1. **欢迎一行**：先给一句友好的开场，说明本插件是学术研究助手，能帮你做深度研究、写论文、论文评审、文献综述、实验规划。

2. **问目标（固定选项）**：用「固定选项点选协议」提问「你现在最想先做哪件事？」（规划模式弹点选卡片，否则编号列表）：
   - 深度研究（把模糊想法收敛成研究问题、做文献综述）
   - 写论文（大纲、摘要、正文起草、引用格式）
   - 论文评审（模拟审稿人、出编辑部决定信）
   - 文献综述（系统检索与综合某一主题的研究）
   - 完整管线（从研究问题一路做到修改后的稿件）
   - 只想先了解（先看教程，不马上动手）

3. **按所选场景给示例提示词**：给出**一句可直接复制的简体中文示例提示词** + 一行说明它会触发哪条工作流（参见「工作流路由」表）。示例提示词一律用中文。

4. **问下一步（固定选项）**：再问「要不要现在试试？」（现在试 / 换场景 / 结束）：
   - 现在试：引导用户把示例提示词发出来，并提示套件会自动安排流程。
   - 换场景：回到步骤 2 重新选场景。
   - 结束：收尾，推荐 `GETTING_STARTED_ZH-CN.md` 教程与 README 参考手册。

## 五场景示例提示词速查（简体中文）

| 场景 | 示例提示词（可直接复制） | 触发工作流 |
|---|---|---|
| 深度研究 | `用学术研究套件帮我做一份系统综述方案，主题是高校质量保障中人工智能的采用情况。` | `deep-research` |
| 写论文 | `用学术研究套件把我的这些笔记整理成论文大纲和写作计划。` | `academic-paper` |
| 论文评审 | `用学术研究套件帮我评审这份稿件，并给出一封期刊风格的编辑部决定信。` | `academic-paper-reviewer` |
| 文献综述 | `用学术研究套件帮我规划一篇关于高校质量保障中人工智能采用情况的系统文献综述。` | `deep-research` |
| 完整管线 | `用学术研究套件从研究主题到修改后的稿件，走一遍完整的研究到论文流程。` | `academic-pipeline` |

## 约束

- 本命令只做引导，不执行具体工作流；用户一旦给出具体任务，交由「工作流路由」正常处理。
- 面向新手的引导一律使用简体中文示例提示词；若用户明确要求英文输出，再按其要求调整。
- 对专业术语（如「文献综述」「系统综述」「苏格拉底式收敛」）首次出现时附一句大白话解释。
- 不要求用户具备学术背景；用词平实，少堆术语。
